# QuantumultX 自用配置目录说明

这个目录用于存放我的 Quantumult X 自用配置、分流规则和阶段性说明文档。

当前目录里的文件可以分成两类：

- 仍在使用的规则与当前主配置
- 不同时间点保存下来的自用配置版本

## 当前在用

如果只看目前仍在实际使用、需要维护的内容，优先关注下面 3 个文件：

| 文件 | 作用 | 说明 |
| --- | --- | --- |
| `quantumult_20260409.conf` | 当前主配置 | 目前实际维护的 Quantumult X 配置文件，已经采用“链式代理 / 中转 / 直连”三池结构。 |
| `academy.list` | 学术站点分流规则 | 当前仍在使用的本地规则文件，内容很小，单独维护更方便。 |
| `Gmail.list` | Gmail 分流规则 | 当前仍在使用的本地规则文件，用于 Gmail 相关域名强制走代理。 |
